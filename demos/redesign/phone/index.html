Checkpoint 6, design round. These are static proposals using the existing synthetic Passat and Wikimedia photos. No live listing is fetched. Production pages have not changed. English UI and Estonian seller message; each screen is shown in light and dark at 390 × 844.

Inside each frame, scroll, swipe the gallery and report cards, try Back and Next, tick the checklist, and copy the message. Open full size to check 360px, 430px or landscape. The ET/EN labels are illustrative in this design round.
