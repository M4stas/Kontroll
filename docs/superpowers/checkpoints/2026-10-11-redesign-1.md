## What changed

Start, listing and report pages use Geist and Geist Mono with latin and latin-ext
subsets. Shared tokens define the light and dark palettes. A shared header provides
the logo and ET/EN links, including report pending and access states. Controls use
pill buttons and rounded fields. Status, notice and access panels use soft cards.

The report no longer overrides the page with navy colors. Finished states use the
accent. Warnings use the attention color. Placeholder text uses the secondary text
color for contrast. Page layouts, copy, routes and data loading retain their existing behavior.

Three small spec rulings extend the literal task list. The native evidence button
also uses the pill radius. Reduced-motion rules disable the new button transforms.
Remaining legacy RGB fills and mismatched state colors now use the specified token
roles. Review feedback restored retrying diagnostics to the amber attention token;
running diagnostics retain the accent color. Each ruling is a focused CSS change that can be reverted independently.
